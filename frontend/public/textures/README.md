# Earth imagery

Earth surface, night lights, normal/specular, and cloud textures are bundled locally from the Three.js examples distribution:
https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets

The imagery is supplied by the Three.js examples collection. The Three.js distribution is MIT licensed; see the upstream repository for source attribution. These are geographical visualization textures, not live satellite imagery. No texture CDN is needed at runtime.

The ground-map country boundaries are Natural Earth 1:110m public-domain data:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
